# ISSA Academy

Version: 1.0

Status: Production Development

---

# Project Goal

ISSA Academy is a professional online learning platform where students can purchase courses, watch lessons, track progress, complete courses, and download certificates.

The system includes a Student Portal and an Admin Portal with Firebase Authentication, Firestore, and Firebase Storage.
